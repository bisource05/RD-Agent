## What it is

An agent that runs the quant research loop by itself: propose a factor or model, write the code, test it, learn from the result and repeat.

## Caution

It writes and runs code, so run it on an isolated machine with no real credentials on it.

## Status

Forked Oct 27, 2026. Nothing here has been run, configured, or connected to any account, API key, or real money. Paper / dry-run first, and only after a walk-forward backtest with fees, a look-ahead check, and 30 days on paper.
